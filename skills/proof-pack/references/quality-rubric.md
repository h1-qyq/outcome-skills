# Proof Pack quality rubric

Use this after the gateway has returned a verified artifact during the free public test.

| Required slot | Pass condition |
| --- | --- |
| `## PROOF HEADLINE` | Exactly one concise, source-supported headline. |
| `## PROPOSAL BLURB` | Exactly two sentences; unsupported language is labeled. |
| `## CASE STORY` | 120–180 words, or an equally concise locale-appropriate story; preserves source facts. |
| `## EVIDENCE BULLETS` | Exactly three; each is source-traceable or visibly `Derived`. |
| `## SOCIAL POST` | One standalone version with no new claim. |
| `## SALES-CONVERSATION VERSION` | One concise spoken version with no new claim. |
| `## CLAIM TRACEABILITY` | Use exactly `Output claim`, `Input support`, and `Status` columns. Every status is `Supported`, `Assumption`, or `Placeholder`; a derived claim is `Supported` with `Derived: <formula>` in Input support. |
| `## MISSING EVIDENCE` | Missing definitions, controls, comparison data, names, and quotes remain explicit. |
| `## QUALITY CHECK` | Confirms all slots, numeric fidelity, quotation fidelity, cautious causality, and artifact-only guarantee. |

For a derived value, require the literal `Derived` label, the original source figures, and the calculation. Do not replace an original figure with derived arithmetic. Treat an observed before/after result as association unless the supplied evidence establishes causation. Quotation marks may surround only exact buyer-supplied wording.

A public-test evaluation must state that access and gateway response are controlled fixtures and that no real money moved.
