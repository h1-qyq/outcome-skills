# Outcome Offer quality rubric

Use this after the gateway has returned a verified artifact during the free public test.

| Required slot | Pass condition |
| --- | --- |
| From-to outcome | States the buyer's starting and desired state without unsupported performance claims. |
| Product name | Specific working name; a non-source name is labeled as an assumption. |
| Buyer | Names the buyer from input or as a labeled placeholder. |
| Buying moment | Identifies a source-supported moment or a labeled assumption. |
| Deliverables | Matches source facts; unknown scope remains a placeholder. |
| Three benefits | Exactly three, each traceable or labeled. |
| Risk reversal | Bounded to the named deliverable; unknown terms remain a placeholder. |
| Three headlines | Exactly three; no invented claims or commercial terms. |
| Sales block | A coherent, paste-ready block that preserves labels for unknown facts. |

Score each item as pass, needs labeled assumption, or fail. A public-test evaluation must state that access and gateway response are controlled fixtures and that no real money moved.
